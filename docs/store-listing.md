## App Privacy ("nutrition label")

Answer **"No, we do not collect data from this app."**

- The app makes no network requests and has no analytics, advertising or crash-reporting
  SDKs.
- Pins, saved values and settings stay on the device, in the app's own storage.
- **Feedback:** the in-app feedback form opens the user's own Mail app with the message filled
  in. Nothing is sent unless the user sends the email, and the app doesn't collect it, so this
  isn't "collection" under Apple's definition.
- Clock uses the device's time-zone setting and never requests location.

**Export compliance:** the app uses no encryption beyond what iOS provides. The app's Info
settings already include `ITSAppUsesNonExemptEncryption = NO`, so App Store Connect doesn't ask
for each build. If it ever does, answer "None of the algorithms mentioned above".

### Regenerating the artwork

1. Take new raw screenshots in the iPhone 6.9" (e.g. iPhone 18 Pro Max) and iPad 13" simulators
   with `xcrun simctl io <device> screenshot docs/screenshots/<device>/raw/<name>.png`, keeping
   the same file names. To keep the status bar tidy:
   `xcrun simctl status_bar <device> override --time 9:41 --batteryState charged --batteryLevel 100`.
   For the Clock shot, set `--time` to the current time instead, so it matches the Local time
   row.
2. From the repo root, run:
   ```
   swiftc -module-cache-path /tmp/swiftcache docs/tools/render_store_assets.swift -o /tmp/render_store_assets
   /tmp/render_store_assets
   ```
   This flattens the raw screenshots, renders the captioned ones (including the 6.3" and 6.1"
   iPhone sets, made from the 6.9" shots), and redraws the banner and the creative assets.
   Captions are defined at the top of the script.
